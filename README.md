A clean and interactive To-Do List application built using HTML, CSS, and JavaScript. This project helps users manage their daily tasks efficiently with features to add and delete tasks dynamically.

## Features ✨
- Add new tasks dynamically using an input field.
- Remove completed or unwanted tasks instantly with a delete button.
- Clean, modern, and responsive UI.

## Technologies Used 🛠️
- **HTML5:** Page structure and input elements.
- **CSS3:** Styling, Flexbox layout, and hover effects.
- **JavaScript (Vanilla):** DOM manipulation, event listeners, and dynamic element creation.
